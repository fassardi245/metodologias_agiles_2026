# Ejercicio Nro: 2

## Enunciado
¿Qué es para vosotros el desarrollo de software?

- ¿Ejemplos de desarrollo de software en los que hayas participado? ¿Ejemplos que conozcas?
- ¿Cuál es el papel del desarrollador en el desarrollo de un proyecto software?
- ¿Hay otros papeles importantes en el desarrollo, aparte del desarrollador?
- ¿Cuándo se ha desarrollado un buen software?

## Resolución

Para mí, el desarrollo de software es un proceso de análisis, diseño, construcción, prueba y mejora de soluciones que buscan resolver una necesidad concreta de usuarios o de una organización. No se trata solo de programar, sino de entender un problema, pensar una solución viable y construirla de manera ordenada, eficiente y mantenible.

Realice un software en la materia de tercero llamada ingeniería de software con 2 compañeros. Hicimos un proyecto full-stack de un E-commerce de tienda de ropa utilizando como tecnologías Next.js, React, y como base de datos noSQL Sanity.io.

Si, además del desarrollador esta el analista, el tester, el diseñador, el líder del proyecto que aplique metodologías eficientes, etc.

Considero que se ha desarrollado un buen software cuando funciona correctamente, resuelve el problema para el cual fue creado, es usable, seguro, confiable y puede mantenerse o mejorarse con el tiempo. También es importante que cumpla con los requerimientos del usuario y que pueda adaptarse a cambios sin problemas.
