# Ejercicio Nro: 5

## Enunciado
Proponga cinco elementos que ayuden en el desarrollo de software referido a la propiedad de flexibilidad que se requiere. 

Ejemplo: 
Diseño para el cambio, 
Ocultamiento de la Información, 
Herramientas de especificación
Etc.

## Resolución
1- Modularidad
Separar el sistema en partes para poder cambiar algo sin romper todo.
2- Bajo acoplamiento
Que las partes dependan lo menos posible entre sí.
3- Alta cohesión
Que cada módulo tenga una función clara y no mezcle de todo.
4- Reutilización de código
Usar componentes o funciones que sirvan en varias partes sin rehacer todo.
Pruebas frecuentes
Permiten hacer cambios con más seguridad y detectar rápido si algo se rompió.
